# Windows quick start

The original setup/test stage is complete. The current Windows instructions are in [yosys_windows.md](yosys_windows.md).

Run `run_windows.bat` for the four RTL tests or `run_synthesis_windows.bat` for the complete flow. Existing waveform paths remain `build/rv32i.vcd`, `build/rv32i_edge.vcd`, and `build/rv32i_decode.vcd`.
